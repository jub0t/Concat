## How to agree

Two things, both needed before a pull request can be merged:

1. **Sign off every commit**, with your real name and a working email address:

   ```
   git commit -s -m "your message"
   ```

   which appends:

   ```
   Signed-off-by: Your Name <your.email@example.com>
   ```

2. **Confirm once**, in a comment on your first pull request, that you have
   read these terms and agree to them. The pull request asks you for it.
