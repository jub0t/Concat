# Concat audit, 9 October 2026

Where the codebase stands five days after the 4 October audit, at
`99c3e26` (9 October), 62 commits past the 0.2.6 tag and 54 commits past
the last audit. Same method, same scales, and every finding from the 4th
(and what was carried from the 28th) re-verified against today's tree.
Every finding names a file and a line. The sibling
`AUDIT-2026-10-09-QUICK.md` is this audit as a one-screen scorecard.

**How it was done.** Four reviewers each read one part of the tree in
full: the window's Rust, Slint and locales; host, server, API and CLI;
media, render, export and core; project, effects, text, vision, speech,
Android, perf, CI and release. Each re-verified the 4 October findings in
its part, scored it and reported new findings with locations. The four
headline items (a release built from `main` instead of its tag, the
Windows test hang that keeps `main` red, the Android key in pull-request
builds, the non-atomic audio mux) were re-read by hand against the code
and the workflow runs before they went in. Line, test and `unsafe`
tallies come from the tree; `cargo fmt --check`,
`cargo clippy --workspace --all-targets`, `cargo test --workspace`,
`scripts/locales.py --check`, `scripts/models.py --check` and
`cargo run -p concat-perf --release -- --check` were run on this machine
(Apple Silicon, macOS 26) today. The app itself was not launched; the
Android build was compile-checked for its target and the 0.2.6 APK was
run on an emulator to the point where its window exits.

**What also happened today.** Six fixes landed on `main` during the
audit, after the reviewers had started: an export makes its folder
(38e45a9), a phone's export goes into Movies (63f2633), a still keeps its
shape on the monitor (89f5ddd), a CJK fallback face and five installer
languages (eb18dbd, corrected by the commit at the head), a detached
sound moves on its own (e11006e), and glyphs sit on whole pixels at 1x
(3989e59, a vendored patch of Slint's Skia renderer). The reviewers judged
them; two findings below are about them.

**Scale.** 0 to 10. 8 and up means "keep doing this"; 5 to 7 means
"works, with known debt"; 4 and under means "will bite at the next order
of magnitude, or already bites".

## 7. What is good, and should stay that way

- **The placement rule is a model rule.** `concat-project/src/placement.rs`
  decides where a clip lands, for the window, the API and the CLI alike,
  with ten tests; the drag asks it as it goes so the echo shows where the
  drop will land (faa6da9).
- **`Catalogue::add` refuses every take-over with a reason**, the built-in
  author is reserved, a LUT must be a plain `.cube` beside its manifest,
  and `replacing` carries keyframes through the knob expression and clamps
  them (`catalogue.rs:1021-1080, 552-622, 727-744`; `manifest.rs:533-537`).
- **Model downloads are pinned to commit URLs with digests**, an empty
  digest is refused, archives are verified before `unpack_in` into a
  staging folder and renamed once (`chatterbox.rs:120-178`,
  `transcribe.rs:118`, `concat-vision/src/models.rs:83-101`,
  `concat-host/src/models.rs:295-301`, `tts.rs:522-580`).
- **Rational time is done carefully**: i128 intermediates, `checked_new`
  for file values, `FrameRate::checked` judged in lowest terms with a test
  of 60000000/2002000 (`time.rs:100-122, 351-358, 445-456`).
- **Hardware decode falls back at all three stages** (open, copy-back,
  send) and `resume_in_software` picks up after the last delivered pts
  (`decode.rs:640-647, 769-794, 830-843, 873-907`).
- **The prefetcher cannot be wedged by a panic**: a `Finished` drop guard
  plus `catch_unwind`, and the queued-vs-pinned read documented under one
  lock order (`prefetch.rs:288-296, 415-450`).
- **Constant-time token compare shared by both transports**, minted from
  `getrandom`, bounded line reads before auth, a 10 s auth timeout, with
  tests (`token.rs:16-36, 52-64`; `json.rs:35-40, 256-263, 385-414`).
- **Atomic project save** (temp, `sync_all`, rename) and a session that
  refuses a newer or unreadable document (`projects.rs:171-195`;
  `session.rs:80-104`). The export's picture path is atomic the same way;
  the sound path should be (finding 4).
- **The epoch gate covers art now**, `spawn_frame` publishes only the
  picture during playback, and `forget_art` drops every per-project cache
  on open and close (`host.rs:197-254, 312-322`; `studio.rs:2093-2102`).
- **`platform.rs` keeps platform differences in one file with the reason
  and issue at each branch**, and the phone's publish hook is confined to
  it, off the UI thread, a no-op on a desk (`platform.rs:336-351, 439-461,
  599-665`).
- **`COLR` glyphs are probed, not trusted**: anything beyond solid layers
  falls back to the outline; a strike that lies about its size is
  rejected (`concat-text/src/lib.rs:630-713, 1056-1071`).
- **Very few panics in the window**: three invariant `expect`s in 22.5k
  lines, and a startup failure reaches the user through a native dialog
  and the log (`lib.rs:126-130`).
- **The fixes of the day each carry a test that fails without them**: the
  still's shape reads the stage either side of the picture; the export
  folder test asserts the folder whatever the GPU does; the CJK face is
  held to the locale files' characters.

## 9. Caveats

Scores are judgements over code, calibrated against the 4 October scores
but not measured against users or another editor. Every crate was read
in full by one of four reviewers; the headline findings were re-read by
hand. Findings marked (verified) were read at the line and, where a
command could show it, run; (reasoned) means the path was followed
through the code and not executed. The perf table ran on a loaded
machine and is a floor. The app was not launched on a desk; the 0.2.6
APK ran on an emulator only as far as its window's first second, which
was enough to read the encoder probe and not enough to drive the editor.
Two of the day's fixes, Windows text and the phone's Movies publishing,
have not been seen on the hardware they are for. `cargo audit` was not
run.
