## 1. Where Concat stands

**Reach is real.** About 205 000 binary downloads across releases. v0.2.7
drew 126 218 in its week as Latest: Windows 43.1%, Android 35.0%, iOS 8.1%,
macOS 7.3%, Linux 6.5%. Traffic is mass-market (Google, Facebook), not
developers. Retention is not: only about 1% of v0.2.7 installs came back
through the in-app updater (the manifest was fetched 1 339 times).

**The engine is the strongest part.** The server work that slipped through
two audits landed with tests (363800f): no pre-auth fd exhaustion, no
blocking stop, a real connection count. Phones decode 8-bit H.264, HEVC,
VP9 and AV1 on MediaCodec (2969e02). Packets refused on a full codec are
sent again (ac8a654). The workspace runs 984 tests with 0 failures, and
clippy and fmt are clean.

**The shell is where users are lost.** The first-ten-minutes failures from
the last two audits are still mostly open, on the two biggest platforms:
safe start that never lets go, Android Back that quits, a phone timeline
that moves clips on a tap, an unsigned Windows build in no store. Feature
work keeps outrunning them: 175 commits in five days, `studio.rs` up
1 578 lines to 12 739, `start()` up 370 to 2 240.

**Nothing fixed today has reached anyone.** v0.2.8 was tagged before
today's work. The website still links v0.2.7 and its checksum link now
points at 0.2.8's file, so a site download fails its own hash check.

## 5. Open findings, High

**H1. Safe start makes any early death permanent.** `lib.rs:2454-2475`
treats a death in the first 15 s as a driver crash and sets
`software_gpu` for good. A Task Manager kill, a Windows logoff (winit
0.30.13 handles no `WM_ENDSESSION`), or a panic opening a corrupt project
all count. Since b5e6c08 that also puts exports on WARP with FXC, where
the repo's own test note says package compiles "ran past five minutes".
Compiles have no deadline and Cancel cannot reach them, so a blurred
export looks hung. The notice shows once. `--smoke` exits without clearing
the mark (`lib.rs:2381, 2385`), so a developer's smoke run forces the next
launch into software. Errors returned before the loop drop the mark, so a
reported GPU failure repeats with no fallback. Sources: window N3,
media H1, startup review.

**H2. Android Back quits, and Android saves nothing on the way out.** No
`Key.Back` handler exists (`app.slint:504-539`); Slint finishes the
activity on an unhandled Back (`javahelper.rs:788-811`). Slint ends the
loop on `Destroy` and ignores Pause and Stop
(`androidwindowadapter.rs:271-273`), then `leave(0)` exits without
`close_project` (`lib.rs:2433`). Back with Export open kills the export;
a background kill loses the autosave window.

**H3. The phone timeline moves clips on a tap.** The drag threshold is
4 px against Android's ~8 dp slop (`lanes.slint:591`). Every press
selects; past 4 px it commits a move with an undo step
(`studio.rs:4804-4978`). Swipe-to-scrub only starts on empty lane or the
24 px ruler. A pinch's first finger selects clips and can move them.
Targets are 24-36 px throughout (transport, zoom chips, pills, `Theme.h`
28 px), with no phone UI scale. CapCut gates moves behind a long-press.

**H4. CI on `main` tells nobody anything.** Of 60 phone runs on `main`
since 16 October, 50 were cancelled by a newer push and 7 failed; of 60 CI
runs, 28 failed and 22 were cancelled. The locale and fmt gates still sit
before clippy and tests in one job (`ci.yml:136-141`), so a string slip
hides everything (it happened today). Releases pass only because they
re-run CI on the tag.

**H5. No trust chain end to end.** Windows unsigned (`WINDOWS_CERTIFICATE_PFX`
unset; a release still passes without it, `build-app.yml:1036`). macOS
ad-hoc and not notarised; iOS ad-hoc. No store or package manager the
project runs. The updater checks downloads against a digest published in
the same release (S1, `updates.rs`, unchanged since 12 October). The
Android signing key changed between v0.2.5 and v0.2.6, so the 15 206
people on 0.2.5 cannot update in place. No Android developer registration
ahead of Google's verification rollout.

**H6. macOS minimum version is not what ships.** The bundles declare
12.0; CI logs list ten Homebrew FFmpeg/OpenSSL libraries built for 14.0
(Intel) or 15.0 (Apple silicon), and the check only warns. The 0.2.8 note
"Intel Macs open on macOS 12 again" is unproven. (Reviewer-verified from
CI logs; not re-checked here.)

**H7. Export recovery takes the road that crashes hybrid laptops.** When
a device dies under an export on the window's lent device, recovery opens
a fresh high-performance DX12 device (`concat-export/src/lib.rs:1530`),
the second-device path #202 ties to NVIDIA hybrid crashes; the sibling
also shares the window's error counter (`gpu.rs:960-963`).

**H8. Captions start early (#438).** Whisper runs with no voice-activity
detection or token timestamps and raw segment times
(`transcribe.rs:481-545`), so each pause is swallowed into the next
caption. A contributor (D3monX) has two working branches and offered PRs;
left to them deliberately.

## 6. Open findings, Medium

Grouped; full evidence in the area reports.

- **Data and projects.** Paste after switching projects inserts the other
  project's footage under a reused media id, or fails silently
  (`studio.rs:8370-8432`, `commands/mod.rs:890`). Copy/paste/duplicate drop
  mask, stabilize, background, cutout and enhance (`studio.rs:2161-2179`).
  Preferences are written non-atomically and any parse failure resets all
  of them (`prefs.rs:258-272`). The project lock opens unguarded on any I/O
  error, including OneDrive or antivirus sharing violations
  (`concat-api/src/lib.rs:183-189`). Agent-opened projects stay locked
  until the server ends (`json.rs:332-335`).
- **Server and agents.** One shared auth-throttle bucket for every local
  caller: a web page's fetch to port 7420 keeps `concat --mcp` out
  (`json.rs:93-97, 228-240`). MCP hints call `preview_frame` read-only
  while it can overwrite any file under home (`tools.rs:445-453`). The
  shipped `concat --mcp` is never run in CI, and its panic nets do nothing
  under `panic = abort`.
- **Render and media.** Any live adjustment layer turns every packaged
  transition into a plain dissolve (`concat-export/src/lib.rs:1958-1964`):
  the most likely code-level cause of #448, which today's GPU test
  bypasses. GLES phones end an export after two 2.15 s waits. The default
  export moved to single-pass ABR at upload bitrates with x264 `veryfast`
  (~8 Mb/s at 1080p30, half the old CRF; unmeasured). 3 MediaCodec slots,
  first-come, never reclaimed.
- **Keyboard.** Destructive chords fire while typing (Ctrl+B splits the
  title being edited; Backspace in a read-only field deletes a clip); no
  guard while a sheet is open; letter shortcuts dead on Cyrillic, Greek,
  Hebrew, Arabic and Persian layouts, all of which ship as languages.
- **Phone.** Toast and tooltips not inset; no soft-keyboard inset; Select,
  SegmentedControl and Switch assign their own bindings, so Captions shows
  Top and places at the bottom after a reopen; no RTL; no accessibility
  names; microphone permission dead end on Android.
- **Downloads.** No size cap on model or sound downloads; phone FFmpeg and
  sherpa-onnx builds pulled unverified into the signed APK; the model
  mirror (`models-v1`) returns 404 and its workflow never ran.
- **Product claims.** README ticks iOS, Android and Windows ✅ against an
  unanswered iOS launch crash, an APK nobody has started and ten open
  Windows crash issues. "4K scrubs smoothly" has no measurement. The 0.2.8
  notes say "Q and E cut the selected clip"; Q and W delete left/right and
  E is unbound.
