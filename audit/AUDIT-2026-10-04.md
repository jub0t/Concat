# Concat audit, 4 October 2026

Where the codebase stands six days after the 28 September audit, at
`a1e8f11` (3 October), 60 commits past the 0.2.5 release. Same method, same
seven scales, same nine reviewers' split, and every one of the 18 findings
from the 28th (and the handful carried from the 23rd) re-verified against
today's tree. Every finding names a file and a line. The sibling
`AUDIT-2026-10-04-QUICK.md` is this audit as a one-screen scorecard.

**How it was done.** Nine reviewers each read one part of the tree in full
(core and project; media; render and effects; export and host; the window's
Rust; the Slint UI and locales; the API, server and CLI; speech, vision,
text, Android and the model manifest; tests, CI, build, docs and release),
re-verified the 28 September findings assigned to them, scored their part
and reported new findings with locations. The headline items (the
`[[replaces]]` hijack, the playback audio offset, the red CI) were re-read
by hand against the code before they went in here. Line counts, test counts
and the unsafe, unwrap and panic tallies come from the tree;
`cargo fmt --check`, `cargo clippy --workspace --all-targets`,
`cargo test --workspace` and `cargo run -p concat-perf --release -- --check`
were run on this machine (Apple Silicon, macOS 26). The app itself was not
launched.

**Status of this document.** Complete: all nine reviews are in and folded
in below. No row is provisional.

**Scale.** 0 to 10. 8 and up means "keep doing this"; 5 to 7 means "works,
with known debt"; 4 and under means "will bite at the next order of
magnitude, or already bites".

## 7. What is good, and should stay that way

- **The layering, still.** FFmpeg is only in concat-media (`grep` finds no
  other crate naming `ffmpeg-the-third`); `FrameSource`/`FrameSink` the
  only seam; the CPU compositor a test oracle and nothing else.
- **`recovered`: three deaths, two kinds of successor, the black frame
  redrawn, the reason in the log** (`concat-export/src/lib.rs:1189-1213`,
  `concat-render/src/gpu.rs:3439-3455`), and the proof that it cannot
  write a partial output: the silent file is renamed or muxed only after
  success and removed on error (`lib.rs:960-982`).
- **`hold` as one boolean read in exactly the two places every renderer
  agrees on** (`concat-core/src/timeline.rs:295-297, 325-327`), with the

  transitions.

  (`concat-media/src/prefetch.rs:374-392, 408-427`).

| 2. Remote page defaults, seats after auth, drop the connection clone, `catch_unwind` the Hub, lend the device | nothing (one line changed in the API, none in the server) |

| 6. Pipeline the export, index the mixer, `Arc` the bin | nothing |
| 7. Speech, enhance, proxies and CBR as API verbs | nothing; the gap grew by four window-only operations |

None of the seven was taken up. What landed instead is a week of the
window: a razor, a scrollbar, a volume line, keyboard menus on every
platform, Save Frame and Save Audio, an export sheet with a picture, logs
that read as what the person did, shapes, batch title styling, Wayland
drop, Linux window edges, Windows data folders and Store packaging,
hardware encoders, Chatterbox on DirectML, and an export that survives a
dead GPU. Each of those is well made at the seam it touches: the new
gestures go echo-then-command, the new workers are epoch-gated, the new
`unsafe` is argued, the device recovery cannot write a partial file. The
app is more pleasant to use than it was.

What the week cost is of three kinds. The first is the gate: `main` has
not been green since the release, fmt has been the only check to run for
71 commits, and the version and CHANGELOG do not know the week happened.
The second is the engine debt of the 28th, untouched and in three places
worse: `[[replaces]]` went from "drops keys" to "a package can hijack a
built-in", the HDR proxy from "not regenerated" to "written under the wrong
name", and the frame-rate ceiling from "no ceiling" to "a panic in the
export". The third is a new correctness seam in the two paths the audit of
the 28th had not read in full: the preview's sound is off by the stream
start on MPEG-TS files, and shapes vanish under 0.2.5.

**Recommended order.** Each line is an hour to a few days, and each closes
a finding above.

1. `cargo fmt`, push, watch it go green; put `rust-toolchain.toml` into the
   CI job; isolate the two locale tests; then write the Unreleased section
   and bump to 0.2.6. (1, 15, flaky tests)
2. Refuse a `[[replaces]]` naming a live package at install; carry keys
   through `replacing`; tell the person when `upgrade_links` changed a
   document; run the trial at `params_at(Max)` on a `sibling()` compositor.
   (2, 6, 28 Sept #7)
3. `AudioDecoder::open` takes `start_of`, seeks and trims at
   `start + offset`, with an MTS fixture that has sound. (3)
4. Bump `DOCUMENT_VERSION` for shapes so 0.2.5 refuses rather than deletes;
   keep an unknown kind's name in `extra`; give `ClipPatch` a `shape`;
   grow the round-trip test to all 44 commands. (5)
5. A `locales.py --check` that flags values equal to English; the six
   literals and the category bar through `I18n`; the export rate from the

8. Then the 28 September list, in its order: sign the update; the Remote

After those, phase 4 of the HDR plan (a true HDR preview), then phase 5

## 9. Caveats

Scores are judgements over code, calibrated against the 28 September
scores but not measured against users or another editor. Every crate was
read in full this time; nothing is provisional. Findings marked (verified)
were read end to end by the reviewer and the three headline ones re-read
by hand; the rest rest on one reviewer's reading and a line number you can
open. The hardware encoders and DirectML could not be exercised on this
machine; what is said of them is read from the code and the workflows. The
app was not launched: "user likeability" is judged from what the UI code
does, not from users.
