## เกี่ยวกับ Concat

Concat คือโปรแกรมตัดต่อวิดีโอที่ฟรีและเป็นโอเพนซอร์ส บน macOS, Windows, Linux, Android และ iOS ทำได้ครบในสิ่งที่งานตัดต่อส่วนใหญ่ต้องใช้ ทั้งคำบรรยายอัตโนมัติ แยกเสียงพูด แปลงข้อความเป็นเสียงพูด ลบพื้นหลัง แอนิเมชันและคีย์เฟรม เอฟเฟกต์และไตเติล ตัดต่อหลายแทร็ก และส่งออก 4K โดยไม่มีข้อแม้ใด ๆ ไม่มีลายน้ำ ไม่ต้องมีบัญชี ไม่ต้องสมัครสมาชิก ไม่ต้องอัปโหลด

ทุกอย่างทำงานบนเครื่องของคุณเอง ด้วยเอนจิน Rust แบบเนทีฟพร้อมตัวคอมโพสิตบน GPU ติดตั้ง ลากฟุตเทจเข้ามา แล้วตัดได้เลย โมเดล AI สำหรับคำบรรยาย เสียงพูด และการตัดพื้นหลัง ดาวน์โหลดครั้งเดียวจากหน้าการตั้งค่า แล้วหลังจากนั้นก็ใช้งานแบบออฟไลน์ได้ ฟุตเทจของคุณไม่เคยออกจากดิสก์ของคุณ

**เหมาะสำหรับ:** TikTok, Reels และ Shorts, วิดีโอ YouTube, วิดีโอสอนและการบันทึกหน้าจอ, คลิปพอดแคสต์, มีม

**ใช้กับโปรแกรมอัตโนมัติได้ด้วย:** มี API แบบ JSON-RPC เพื่อให้สคริปต์และเอเจนต์ AI ใช้ตัดต่อวิดีโอได้เช่นกัน

## จุดเด่น

- 🚫 **ไม่มีลายน้ำ ไม่ต้องมีบัญชี ไม่มีส่วนที่ต้องจ่ายเงินเพื่อปลดล็อก** ตลอดไป
- 🔒 **ทำงานในเครื่อง 100%** ไม่มีอะไรถูกอัปโหลด รวมถึง AI ใช้งานออฟไลน์ได้
- 💬 **คำบรรยายอัตโนมัติ** ในภาษาที่คุณพูด สร้างบนเครื่องของคุณ จัดสไตล์แล้วและอยู่บนไทม์ไลน์ทันที
- 🎤 **แยกเสียงพูด** ดึงเสียงพูดออกจากเพลงหรือเสียงรบกวน หรือเอาเสียงพูดออก โดยแต่ละส่วนมีระดับเสียงของตัวเอง
- 🗣️ **แปลงข้อความเป็นเสียงพูด + โคลนเสียง** เสียงในเครื่องฟรี หรือเสียงใดก็ได้จากการอัดเพียงไม่กี่วินาที บนเดสก์ท็อป
- 🧍 **ลบพื้นหลัง โครมาคีย์ และมาสก์** ตัดคนและวัตถุออกให้ ฉากสีเขียวที่คีย์ตัวเอง และมาสก์ซ้อนกันได้บนทุกคลิป แต่ละอันมีโหมดและคีย์เฟรมของตัวเอง
- 🌀 **แอนิเมชัน เข้า ออก และวนซ้ำ** สำหรับคลิป รูปภาพ ไตเติล และรูปทรง ทุกแบบเล่นให้ดูบนการ์ดของมันก่อนที่คุณจะเลือก
- ✨ **เอฟเฟกต์ ฟิลเตอร์ และทรานซิชันกว่า 100 แบบ เอฟเฟกต์เสียง 25 แบบ** ลุคแบบภาพยนตร์ ภาพสั่นและแรงกระแทก เรโทร ไวพ์ ทั้งหมดเห็นสดในพรีวิว ทรานซิชันคือคลิปที่คุณย้ายและตัดแต่งได้เหมือนคลิปอื่น ๆ
- 🎞️ **คีย์เฟรม** ตำแหน่ง สเกล ขนาด การหมุน ความทึบ ระดับเสียง พารามิเตอร์ของเอฟเฟกต์ มีตัวแก้ไขเส้นโค้งในตัว
- 🏃 **ปรับความเร็วแบบแรมป์และเส้นโค้ง** คงที่หรือวาดเอง นุ่มหรือตรง รวมถึงเฟรมค้างและเล่นย้อนกลับ
- 🪄 **เพิ่มคุณภาพและกันสั่น** ฟื้นฟูภาพนุ่มหรือภาพเก่า ได้ถึง 2K ทำให้ช็อตที่สั่นนิ่งขึ้น
- ✂️ **ตัดเร็ว ตัดเป๊ะ** แยก ตัดแต่ง ริปเปิล รวม คำบรรยายและโอเวอร์เลย์ที่เชื่อมกัน ไทม์ไลน์แม่เหล็กถ้าคุณต้องการ ทุกจุดตัดลงบนเฟรมพอดี เหมือนกันทั้งในพรีวิวและตอนส่งออก
- 🎚️ **หลายแทร็ก หลายไทม์ไลน์** ซ้อนวิดีโอ ภาพนิ่ง ไตเติล และรูปทรงได้กี่แทร็กก็ได้ หลายเวอร์ชันของงานตัดต่อในโปรเจกต์เดียว โหมดการผสม ครอป พลิกภาพ
- 📝 **ไตเติลและรูปทรง** ฟอนต์ เส้นขอบ เงา แผ่นพื้นหลัง อีโมจิสี และพรีเซ็ตสำหรับภาษาอาหรับ จีน ฮินดี ไทย และอีกแปดภาษา รูปทรงที่มีไล่สี ดาว เส้นขอบ และเงา
- 🎙️ **เสียงพากย์ และล้างเสียงด้วยสวิตช์เดียว** อัดทับงานตัดต่อของคุณ ลดเสียงรบกวน เพิ่มคุณภาพเสียงพูด ปรับระดับความดัง รวมถึงเสียงกระรอก หุ่นยนต์ โทรศัพท์ และอื่น ๆ
- 📤 **ส่งออก** H.264, HEVC, AV1 ด้วยตัวเข้ารหัสของคอมพิวเตอร์คุณเอง สูงสุด 4K 60 สี 10 บิต
- ⚡ **เร็ว** มีพร็อกซีในตัว เลื่อนดู 4K ได้ลื่น ไตเติลถูกวาดบนทุกคอร์ และทุกเอฟเฟกต์พร้อมใช้ทันทีที่หน้าต่างเปิด
- 🛟 **ทำงานต่อได้บนทุกเครื่อง** เมื่อชิปกราฟิกยอมแพ้ พรีวิวก็ยังวาดต่อไป
- 🤖 **สั่งงานด้วยสคริปต์ได้** มี API แบบ JSON-RPC ที่สคริปต์และเอเจนต์ AI ใช้ตัดต่อวิดีโอได้ ถ้าบิลด์จากซอร์สโค้ดจะได้ gRPC และเครื่องมือบรรทัดคำสั่งเพิ่มมาด้วย
- 🖥️ **macOS, Windows, Linux, Android, iOS** 26 ภาษา แอปเดียวกัน ไฟล์โปรเจกต์เดียวกัน

## ดาวน์โหลด

มีสองช่องทาง:

1. **[เว็บไซต์](https://concat.standalones.org/#download)** จะให้บิลด์ที่เหมาะกับเครื่องของคุณ เริ่มที่นี่
2. **[GitHub Releases](https://github.com/jub0t/Concat/releases)** มีทุกบิลด์สำหรับทุกแพลตฟอร์ม พร้อมตัวติดตั้ง แพ็กเกจ และเช็กซัม สำหรับตอนที่คุณอยากเลือกเอง

Concat อยู่ในช่วง **เบต้า**: ใช้งานได้แล้ว แต่ยังมีจุดที่ไม่เรียบร้อยอยู่บ้าง เจอเมื่อไหร่ [บอกเราได้เลย](https://github.com/jub0t/Concat/issues)

**แพลตฟอร์ม**

- ✅ **Windows** · x86_64 (บิลด์สำหรับ ARM หยุดไว้ชั่วคราว ดู [#326](https://github.com/jub0t/Concat/issues/326)) มีทั้งตัวติดตั้งแบบ setup และ `.msi` หาก SmartScreen บล็อกบิลด์ที่ไม่ได้ลงนาม: **More info** › **Run anyway**
- ✅ **macOS** · Intel และ Apple silicon หาก macOS ไม่ยอมเปิดบิลด์ที่ไม่ได้ลงนาม: `xattr -dr com.apple.quarantine /Applications/Concat.app`
- ✅ **Linux** · x86_64 และ ARM มี `.deb`, `.rpm`, `.AppImage` และแพ็กเกจสำหรับ Arch และยังมี Flatpak บน **[Flatpark](https://flatpark.org/apps/app.concat.editor/)** ซึ่งเป็นรีโมต Flatpak ของชุมชนที่แพ็ก `.deb` สำหรับ x86_64 ของแต่ละรีลีส และอัปเดตตามทุกรีลีส
- ✅ **Android** · โทรศัพท์และแท็บเล็ต
- ✅ **iOS / iPadOS** · iPhone และ iPad ผ่านการไซด์โหลด

✅ รองรับ · 🚧 กำลังพัฒนา · 🧪 รอการทดสอบ

**ความต้องการของระบบ** และขนาดของโมเดลเสริมดูได้ที่[เว็บไซต์](https://concat.standalones.org/guides/system-requirements)
