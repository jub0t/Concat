## เกี่ยวกับ Concat

Concat คือโปรแกรมตัดต่อวิดีโอที่ฟรีและเป็นโอเพนซอร์ส เป็นทางเลือกแทน CapCut บน macOS, Windows, Linux และ Android ทำได้ครบในสิ่งที่คนเปิด CapCut ขึ้นมาใช้จริง ๆ ทั้งคำบรรยายอัตโนมัติ แปลงข้อความเป็นเสียงพูด ลบพื้นหลัง แอนิเมชันคีย์เฟรม เอฟเฟกต์และไตเติล ตัดต่อหลายแทร็ก และส่งออก 4K โดยไม่มีข้อแม้ใด ๆ ไม่มีลายน้ำ ไม่ต้องมีบัญชี ไม่ต้องสมัครสมาชิก ไม่ต้องอัปโหลด

ทุกอย่างทำงานบนเครื่องของคุณเอง ด้วยเอนจิน Rust แบบเนทีฟพร้อมตัวคอมโพสิตบน GPU ติดตั้ง ลากฟุตเทจเข้ามา แล้วตัดได้เลย โมเดล AI สำหรับคำบรรยาย เสียงพูด และการตัดพื้นหลัง ดาวน์โหลดครั้งเดียวจากหน้าการตั้งค่า แล้วหลังจากนั้นก็ใช้งานแบบออฟไลน์ได้ ฟุตเทจของคุณไม่เคยออกจากดิสก์ของคุณ

**เหมาะสำหรับ:** TikTok, Reels และ Shorts, วิดีโอ YouTube, วิดีโอสอนและการบันทึกหน้าจอ, คลิปพอดแคสต์, มีม

**ใช้กับโปรแกรมอัตโนมัติได้ด้วย:** มี API แบบ JSON-RPC เพื่อให้สคริปต์และเอเจนต์ AI ใช้ตัดต่อวิดีโอได้เช่นกัน

## จุดเด่น

- 🚫 **ไม่มีลายน้ำ ไม่ต้องมีบัญชี ไม่มีส่วนที่ต้องจ่ายเงินเพื่อปลดล็อก** ตลอดไป
- 🔒 **ทำงานบนเครื่อง 100%** ไม่มีอะไรถูกอัปโหลด ใช้งานออฟไลน์ได้
- 💬 **คำบรรยายอัตโนมัติ** ใช้ Whisper บนเครื่อง เลือกขนาดโมเดล แล้วรับคำบรรยายพร้อมสไตล์บนไทม์ไลน์
- 🗣️ **แปลงข้อความเป็นเสียงพูด + โคลนเสียง** เสียงฟรีที่ทำงานบนเครื่อง หรือเสียงใดก็ได้จากการบันทึกเพียงไม่กี่วินาที
- 🧍 **ลบพื้นหลัง** คน วัตถุ หรือจะระบายมาสก์เองก็ได้
- 🎞️ **คีย์เฟรม** ตำแหน่ง สเกล การหมุน ความทึบ ระดับเสียง พารามิเตอร์ของเอฟเฟกต์ มีตัวแก้ไขเส้นโค้งในตัว
- ✨ **เอฟเฟกต์ ฟิลเตอร์ และทรานซิชัน 100 แบบ** เรนเดอร์ด้วย GPU เห็นผลสดในหน้าพรีวิว
- ✂️ **ตัดได้รวดเร็ว** แยกคลิป ทริม ripple รวมคลิป เฟรมค้าง ปรับความเร็ว และมีไทม์ไลน์แบบแม่เหล็กถ้าต้องการ
- 🎚️ **หลายแทร็ก หลายไทม์ไลน์** ตัดได้หลายเวอร์ชันในโปรเจกต์เดียว โหมดผสม ครอป พลิกภาพ
- 📝 **ไตเติล** ฟอนต์ เส้นขอบ เงา แผ่นพื้นหลัง พร้อมพรีเซ็ตให้เริ่มต้น
- 🎙️ **ปรับเสียงพูดให้สะอาดด้วยสวิตช์เดียว** ลดเสียงรบกวน ทำให้เสียงพูดชัดขึ้น ปรับระดับความดังให้เท่ากัน แถมเสียงชิปมังก์ หุ่นยนต์ โทรศัพท์ และอื่น ๆ อีกมาก
- 📤 **ส่งออก** H.264, HEVC, AV1 สูงสุด 4K 60 สี 10 บิต
- 🦀 **เอนจิน Rust แบบเนทีฟ** คอมโพสิตบน GPU, พร็อกซี, ถอดรหัสด้วยฮาร์ดแวร์ เลื่อนดูวิดีโอ 4K ได้ลื่นไหล
- 🤖 **สั่งงานด้วยสคริปต์ได้** มี API แบบ JSON-RPC ที่สคริปต์และเอเจนต์ AI ใช้ตัดต่อวิดีโอได้ ถ้าบิลด์จากซอร์สโค้ดจะได้ gRPC และเครื่องมือบรรทัดคำสั่งเพิ่มมาด้วย
- 🖥️ **macOS, Windows, Linux, Android** 25 ภาษา แอปเดียวกัน ไฟล์โปรเจกต์เดียวกัน

## ดาวน์โหลด

มีสองช่องทาง:

1. **[เว็บไซต์](https://concatenate.pages.dev/#download)** จะให้บิลด์ที่เหมาะกับเครื่องของคุณ เริ่มที่นี่
2. **[GitHub Releases](https://github.com/jub0t/Concat/releases)** มีทุกบิลด์สำหรับทุกแพลตฟอร์ม พร้อมตัวติดตั้ง แพ็กเกจ และเช็กซัม สำหรับตอนที่คุณอยากเลือกเอง

Concat อยู่ในช่วง **เบต้า**: ใช้งานได้แล้ว แต่ยังมีจุดที่ไม่เรียบร้อยอยู่บ้าง เจอเมื่อไหร่ [บอกเราได้เลย](https://github.com/jub0t/Concat/issues)

**แพลตฟอร์ม**

- ✅ **Windows** · x86_64 (บิลด์สำหรับ ARM หยุดไว้ชั่วคราว ดู [#326](https://github.com/jub0t/Concat/issues/326)) มีทั้งตัวติดตั้งแบบ setup และ `.msi` หาก SmartScreen บล็อกบิลด์ที่ไม่ได้ลงนาม: **More info** › **Run anyway**
- ✅ **macOS** · Intel และ Apple silicon หาก macOS ไม่ยอมเปิดบิลด์ที่ไม่ได้ลงนาม: `xattr -dr com.apple.quarantine /Applications/Concat.app`
- ✅ **Linux** · x86_64 และ ARM มี `.deb`, `.rpm`, `.AppImage` และแพ็กเกจสำหรับ Arch และยังมี Flatpak บน **[Flatpark](https://flatpark.org/apps/app.concat.editor/)** ซึ่งเป็นรีโมต Flatpak ของชุมชนที่แพ็ก `.deb` สำหรับ x86_64 ของแต่ละรีลีส และอัปเดตตามทุกรีลีส
- ✅ **Android** · โทรศัพท์และแท็บเล็ต
- ✅ **iOS / iPadOS** · iPhone และ iPad ผ่านการไซด์โหลด

✅ รองรับ · 🚧 กำลังพัฒนา · 🧪 รอการทดสอบ

**ความต้องการของระบบ** และขนาดของโมเดลเสริมดูได้ที่[เว็บไซต์](https://concatenate.pages.dev/guides/system-requirements)
