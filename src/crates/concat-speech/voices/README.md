# Stock voices

The recordings Chatterbox reads a stock voice from. Chatterbox has no
speakers of its own: every voice is a few seconds of someone talking.

- `bria.flac`: the first ten seconds of `audio/bria.mp3` from Kyutai's
  delayed-streams-modeling repository
  (https://github.com/kyutai-labs/delayed-streams-modeling), as the
  sherpa-onnx Pocket TTS bundle carried it, at 24 kHz mono. That
  repository's `LICENSE` file is Apache-2.0. Its README licenses the code
  (MIT and Apache-2.0) and the speech-to-text weights (CC-BY-4.0), and
  states no separate licence for the sample recordings, nor who the
  speaker is. See `THIRD_PARTY_NOTICES.md`, "Text to speech".
